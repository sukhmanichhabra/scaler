# A range, not an exact pin: spaCy's PyPI releases get yanked periodically
# (3.8.0 and 3.8.12 both are, as of writing), and an exact pin to a version
# that's since been pulled fails the build outright with no way to
# self-heal -- which is exactly what happened with a prior pin to 3.8.15,
# a version that no longer appears in PyPI's index at all. A range lets
# pip pick whatever the current healthy 3.8.x release is. Capped below 3.9
# to stay on the same minor line as the pinned model wheel below --
# spaCy's own compatibility promise is per minor version.
